# CicloComputer

![Plataforma](https://img.shields.io/badge/Plataforma-Android-green?logo=android)
![Linguagem](https://img.shields.io/badge/Linguagem-Java-blue?logo=java)
![Status](https://img.shields.io/badge/Status-Incompleto-red)
![Progresso](https://img.shields.io/badge/Projeto-Não%20Finalizado-orange)

**CicloComputer é um projeto desenvolvido em Java com o objetivo de criar um GPS voltado para ciclismo, mas que também pode ser utilizado para corrida ou para monitorar velocidade, distância e tempo decorrido. O projeto foi encerrado antes de ser finalizado, por isso apenas uma das telas possui funcionalidade completa. Ainda assim, trata-se de um projeto interessante do ponto de vista educacional e de aprendizado.**

# 📦 Instalação
1. Clone o repositório:

```bash
git clone https://github.com/LucasKalil-Programador/CicloComputer.git
```
2. Abra o projeto no Android Studio.

3. Aguarde a indexação e sincronização do Gradle.

4. Conecte um dispositivo ou inicie um emulador.

5. Execute o projeto clicando em Run (ou pressione Shift + F10).

# 🛠️ Tecnologias Usadas

- Java — Linguagem principal do projeto
- Android SDK — Plataforma de desenvolvimento Android
- Google Location Services API — Para coleta de dados de localização
- Gradle — Sistema de build automatizado
- Material Design — Componentes de UI modernos do Android
